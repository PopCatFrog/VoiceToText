# 🎓 VoiceToText：課堂長錄音轉逐字稿與發言人分離系統

專為大學/研究所課堂長錄音（1.5 ~ 2.5 小時）設計的語音轉文字與說話者分離（Speaker Diarization）方案。基於阿里達摩院 **FunASR** 框架與 **Google Colab (支援 GPU 加速)**。

---

## 🎯 針對特定情境的最佳化

1. **設備與環境最佳化（MacBook 講台收音 + 拯救遠處微弱學生聲音）**：
   - 針對 **MacBook Air M4** 放置於講台/桌面上錄製的 `.m4a` 檔案。
   - **科學前處理順序（先去噪濾波，後動態增益）**：
     - `highpass=80`：濾除講台共振、敲擊聲與冷氣低頻風聲。
     - `lowpass=8000`：濾除 8kHz 以上無人聲頻率的尖銳高頻底噪。
     - `afftdn=nf=-25`：以 FFT 頻譜降噪先壓制背景噪音，提升信噪比（SNR）。
     - `dynaudnorm=p=0.95:m=12:s=15:g=31`：在乾淨語音基礎上，動態提升遠距學生發言音量（最大可放大 12~15 倍），同時保護講師正常音量不破音。
2. **多模型一體化管線 (Pipeline)**：
   - **FSMN-VAD**：語音活動檢測，將 2 小時長音訊智慧切段並過濾無效靜音。
   - **Paraformer-large-zh**：中英雙語高精準度辨識，支援中英混雜術語。
   - **CT-Punc**：智慧還原標點符號（句點、逗號、問號）。
   - **CAM++**：提取說話人聲紋特徵並進行聚類，自動區分「講師」與「學生」發言。
3. **專業名詞熱詞庫（Hotwords）與格式淨化**：
   - 內建 **計算機科學 (CS)**、**數學 (Math)**、**醫學 (Medicine)** 領域術語庫，支援自訂擴充與正則空白清理。
4. **一鍵匯出全格式（含輕量化音檔）**：
   - `.txt`：純文字對話清單。
   - `.md`：智慧排版筆記（同一發言人發言自動整合為段落；若停頓超過 20 秒自動換段）。
   - `.srt` / `.vtt`：標準字幕格式（帶毫秒時間軸與講者標籤，具備時間戳異常防護）。
   - `.json`：包含完整時間軸結構化數據，並自帶專為 LLM (Gemini / ChatGPT) 設計的課堂摘要 Prompt。
   - `.mp3` / `.wav`：去噪增益後的音訊檔（MP3 體積僅約 30~50MB，方便隨身複習）。

## 🚀 如何在 Google Colab 上使用

1. 將本專案中的 [`main.ipynb`](main.ipynb) 上傳到 [Google Colab](https://colab.research.google.com/)。
2. **切換運算資源**：
   - 點擊頂部選單的 **執行階段 (Runtime) -> 變更執行階段類型 (Change runtime type)**。
   - 選取 **T4 GPU** 或 **A100 GPU**（您擁有 Google AI Pro 額度，建議選用 GPU 以大幅提升處理速度）。
3. 將 MacBook Air 錄製的 `.m4a` 音檔上傳至您的 **Google Drive (雲端硬碟)**。
4. 依序執行 [`main.ipynb`](main.ipynb) 中的每個步驟：
   - **步驟 2**：透過 Colab 表單設定 `INPUT_AUDIO_PATH`（若路徑錯誤會自動在 Drive 中模糊搜尋提示）。
   - **步驟 4**：從下拉選單選擇領域（如 `CS` / `Math` / `Medicine`）並填入特定英文專有名詞。
   - **步驟 6 ~ 7**：自動進行辨識並輸出所有格式與音檔至 Google Drive。
   - **步驟 9**：透過 Colab 表單開關，一鍵打包下載逐字稿 ZIP 或去噪 MP3 音檔回本機。

## 🛠️ 常見調整與參數說明

- **學生提問依然太小聲？**
  - 在步驟 3 的 FFmpeg 參數中，可將 `m=12` 提升至 `m=15` 或 `m=20`（最大增益倍率）。
- **老師偶爾被切成兩個 Speaker？**
  - 長錄音中若老師音調大幅變化或走動遠離麥克風，CAM++ 聚類可能有少量片段波動。後續可直接使用產出的 JSON 丟給 Gemini 自動依據「講授脈絡」平滑修正。
